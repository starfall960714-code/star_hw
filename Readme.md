## 步驟一：開發環境與選擇
* **使用工具**：GitHub 網頁端與文字編輯環境，建立專案結構與網頁基本框架
* **挑選幸運物**：選擇「星星」作為主題，象徵永恆的光芒、方向與希望，確立清晰的視覺主軸

## 步驟二：網頁內容與設計
* **幸運物網頁製作**：運用 HTML5 與 CSS3 打造具備高質感的展示頁面，搭配夜空漸層背景與毛玻璃（Glassmorphism）卡片效果
* **內容與故事驅動**：結合文字說明與圖形視覺，介紹星星的象徵意義，希望守護的意思，避免版面太亂

## 步驟三：互動效果設計
* **動態互動效果**：
  * **浮動動畫**：星星圖標具備持續的上下浮動特效
  * **滑鼠懸停 (Hover)**：當滑鼠移到星星上時，會自動放大並帶有旋轉與亮亮的金色發光陰影
  * **點擊動畫 (Active)**：點擊時會產生縮放與反向旋轉互動回饋

## 動態互動腳本工程規劃與落地清單：

依據 Prompt，本專案在 `style.css` 與 HTML 中具體實作了以下互動模組：

| 互動模組 | 技術實現機制 | 使用者體驗回饋 |
| :--- | :--- | :--- |
| **1. 浮動靈動特效 (Float Animation)** | CSS3 `@keyframes` 與 `translateY` 迴圈運算 | 星星圖標持續保持微幅上下浮動，呈現生動、有呼吸感的視覺效果。 |
| **2. 滑鼠懸停發光 (Hover Glow)** | CSS3 `transition`、`scale` 縮放與 `drop-shadow` 光暈 | 滑鼠移到星星上時，會自動放大、旋轉並散發金色溫暖光芒。 |
| **3. 點擊互動回饋 (Click Active)** | CSS3 `active` 狀態與反向旋轉位移 | 點擊星星時會產生輕微縮放與反向旋轉，增添網頁的點擊互動感。 |
